## What is Famnesia?

Famnesia is a Shiny app for anonymising files from Familias, a program
for kinship calculations in forensic genetics. Its aim is to enable
safer sharing of sensitive data, for instance for:

- collaborative work and research
- troubleshooting and software support
- teaching and demonstrations
- reproducible examples and testing

More information is available in the GitHub repository:
<https://github.com/magnusdv/famnesia>.
