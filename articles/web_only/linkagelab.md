## What is Linkage Lab?

Linkage Lab is a pedagogical tool for exploring and understanding how
marker linkage affects likelihood ratios (LRs) in kinship testing. It is
a companion to
[KLINK](https://magnusdv.github.io/pedsuite/articles/web_only/klink.html),
which is a full-featured software for kinship testing, including support
for linkage.

Linkage Lab is described in detail in the KLINK paper: [KLINK: A program
for kinship testing with pairwise linked STR
markers](https://doi.org/10.1016/j.fsigen.2026.103578) (Vigeland and
Gilfillan, 2026).
